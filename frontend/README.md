# Frontend — Reservas Restaurante

SvelteKit + TypeScript. Consume la API FastAPI con cookies HTTPOnly.

## Desarrollo

```bash
npm install
npm run dev
```

Requiere el backend en `localhost:8000`. Vite proxy reenvía `/api` y `/health`.

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run check` — typecheck Svelte/TS
- `npm run build` — build de producción
